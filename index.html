About Me

I'm a Computer Science student at Kent State University (Class of 2028, minor in Computer Engineering). I like taking ideas all the way to launch, and most of what I build has real users or paying customers.

I run FreaksMC, a Minecraft server-hosting business I built solo, shipped NeedlePointer to the App Store, and make Roblox games under DoSa Games. Lately I've been building developer tools: an AI app builder that runs on your own Claude subscription, a C++ playground with a real compiler that installs on your phone, and an AI resume tool with Stripe subscriptions.

I also work as a truck driver and catering coordinator at Taste of Excellence Catering in Strongsville, OH.

Claude Studio

An AI app builder, similar to Replit, that runs on your own Claude subscription

Describe an app in chat and Claude writes it, with a file tree, code editor, and live preview. You log in with your own Claude Pro/Max plan, so there's no shared API key to pay for.

  • "Log in with Claude" via PKCE OAuth, with automatic token refresh
  • Streams multi-file projects; follow-up prompts edit the code with full file context
  • C++ projects compile with g++ -std=c++20 on the server and run with stdin, timeouts, and a console
  • Monaco editor, a sandboxed preview iframe, and a mobile layout with bottom tabs; installable as a PWA
Node.js Express Claude API OAuth Monaco
